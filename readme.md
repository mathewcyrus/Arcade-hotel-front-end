# Arcade Hotel Website

A modern and user-friendly hotel website built with the MERN stack and WebSockets for real-time chat, providing guests with seamless booking and service options, including food ordering, room reservations, event hosting, and office rentals.

## Table of Contents

- [Features](#features)
- [Technology Stack](#technology-stack)
- [Usage](#usage)
- [Images](#images)

## Features

### 1. Room Booking

- Easily reserve rooms with available options and real-time pricing updates.
- **Image slot** - Displays room images for an immersive browsing experience.

### 2. Food Ordering

- Order food directly from the website with an updated menu, delivery to rooms, and special dietary options.
- **Image slot** - Shows a variety of cuisine options.

### 3. Events

- Book spaces for events such as weddings, conferences, or parties.
- **Image slot** - Highlights event spaces and configurations.

### 4. Office Renting

- Rent office spaces by the hour, day, or longer, with additional services available.
- **Image slot** - Displays available office spaces and amenities.

### 5. Real-Time Chat Support

- Get instant assistance from hotel staff using our WebSocket-powered chat system.

## Technology Stack

- **Frontend**: React.js, redux, context, stripe checkout
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Real-Time Chat**: WebSockets

## Usage

- **Navigate** through the site to explore available rooms, food menus, event spaces, and office rentals.
- **Order food, book rooms or office spaces,** and **reserve events** using intuitive forms and availability information.
- Use the **chat feature** for any queries or support.
